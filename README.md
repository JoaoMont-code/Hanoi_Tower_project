# 🗼 Torre de Hanói (Hanoi Tower)

Um projeto desenvolvido em **Java** para simular e resolver o clássico problema matemático e de estrutura de dados da **Torre de Hanói**.

---

## 📌 Sobre o Projeto

A Torre de Hanói é um quebra-cabeça que consiste em três torres e um conjunto de discos de diferentes tamanhos. O objetivo é mover toda a pilha de discos do pino inicial para o pino de destino, respeitando as seguintes regras:

1. Apenas um disco pode ser movido por vez.
2. Um disco maior nunca pode ser colocado sobre um disco menor.
3. Cada movimento consiste em pegar o disco do topo de uma das pilhas e posicioná-lo no topo de outra pilha.

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Java
* **Conceitos aplicados:** Orientação a Objetos (POO), Estruturas de Dados (Pilhas) e Algoritmos de Recursão.

---

## 📁 Estrutura de Arquivos

* `Controller.java`: Classe responsável pela lógica de controle da partida e regras do jogo.
* `Discos.java`: Representação da estrutura dos discos.
* `Torres.java`: Representação das hastes/torres onde os discos são empilhados.
* `AnotacoesProjeto.txt`: Anotações e documentação do fluxo do projeto.
